# 🤖 Intelligent Chatbot with RAG and LLaMA-OpenAI

This project is a **smart chatbot microservice** that leverages modern NLP (Natural Language Processing) technologies and a **Retrieval-Augmented Generation (RAG)** architecture.  
It is designed to provide **accurate, context-aware responses**, making it ideal for applications that require natural interaction and rely on specific knowledge bases.

The project combines:

- **Spring AI** (backend microservice)
- **React** (frontend)
- **Vaadin** (UI components)
- **LLaMA & OpenAI** (language models)
- **RAG architecture** (integrating retrieval and generation)

---

## ⚙️ Features

### 🗨️ Chatbot Modes

1. **General Question Mode**  
   - The chatbot answers general user questions using a large language model (LLM).  

2. **PDF Question Mode**  
   - The chatbot answers questions based on the content of a local PDF file.  
   - Enables context-specific responses by combining document retrieval with language generation.

---

## 🖥️ Tech Stack

- **Backend:** Spring AI (Java)  
- **Frontend:** React, Vaadin  
- **NLP/AI:** LLaMA, OpenAI API  
- **Architecture:** RAG (Retrieval-Augmented Generation)  
- **Data Sources:** PDF documents for knowledge-based queries
